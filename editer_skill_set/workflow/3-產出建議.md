## 三層建議的範例骨架

### 第一層：本年度立即可做（5 月報稅前）

最實惠的補件項目：

1. **加入扶養親屬**：例如 70 歲以上父母同住未報。可省 14.55 萬 × 稅率。
2. **核實薪資費用**（年薪 ≥ 243 萬）：補蒐集服裝、進修、工具的證明，每項 3%、合計 9%。
3. **列舉扣除額補件**：醫藥費、捐贈、保險費、購屋利息、租金特扣。
4. **健保補充保費**：檢查有沒有勾選（不限 2.4 萬）。
5. **長照特扣**：失能親屬若還沒報巴氏量表可申請。
6. **股利二擇一**：年所得 + 股利狀況推算分開 vs. 合併哪個省。

### 第二層：下個年度起的布局

需要事前一年規劃的：

1. **勞退自提 6%**（要在受僱時通知公司）
2. **房屋出租改包租代管**（享每月 6,000 元免稅 + 53% 必要費用）
3. **投資新創／文創**（持股要 ≥ 3 年才能扣 50%）
4. **儲蓄投資特扣**：分散到不同申報戶把 27 萬額度用滿
5. **保險規劃**（要保人 = 被保險人；避免三高短重躉債）
6. **不動產規劃**（自用住宅要件養成：戶籍、滿 6 年無出租／營業）

### 第三層：長期傳承規劃

涉及遺產／贈與／信託的：

1. **分年贈與**（每人每年 244 萬免稅；婚嫁時加 100 萬；夫妻互贈免稅）
2. **附房貸贈與**（書中認為最省稅的不動產移轉方式之一，但要算未來房地合一）
3. **保險作為遺產稅節稅**（壽險 4,000 萬保費 → 1 億遺產減為 6,000 萬，省 500 多萬遺產稅；給付每戶 ≤ 3,740 萬不計入最低稅負）
4. **遺囑＋特留分**（單身者尤其要寫公證遺囑）
5. **配偶剩餘財產差額分配請求權**（夫妻先過世一方的剩餘較多 → 生存方主張差額一半 → 列入遺產扣除額）
6. **信託**：本金自益孳息他益（凍結資產），保險金信託（避免子女揮霍）
7. **2026 年新制提醒**：擬制遺產稅單拆分（憲判字第 11 號）

## 紅線提醒清單（每次都要檢查）

### 1. 三高短重躉債（保險實質課稅原則）

對應 CP-2.10.1：
- **三高**：高齡（≥ 73 歲）、高額（≥ 1,000 萬）、高資產
- **短**：短期內死亡（2 年內，最長到 10 年都被查過）
- **重**：重病投保（癌症、高血壓、糖尿病、中風、洗腎、帕金森、失智、憂鬱、老年退化）
- **躉**：躉繳保費
- **債**：舉債投保

### 2. 二親等買賣的「視同贈與」（CP-3.1.5）

- 必須提供受讓人有自有資金來源證明
- 不能是出賣人貸與或提供擔保向他人借得
- 父母不能事後將取得的價款返還子女

### 3. CFC 制度（CP-1.SS1.1、CP-AF.6）

- 個人＋關係人持有低稅負區外國企業 ≥ 50% 或具控制能力
- 當年盈餘視同分配計入海外所得
- 豁免：盈餘 ≤ 700 萬／實質營運（被動收入比 < 10%）

### 4. 死亡前 2 年贈與（擬制遺產，CP-2.2.2）

- 贈與配偶、第一到第四順位繼承人及其配偶 → 全數回歸遺產
- 已繳贈與稅、土增稅及其利息可抵
- **2026 新制**：配偶單獨負擔擬制遺產對應稅額（不再連坐其他繼承人）

### 5. 重病期間的財產變動（CP-2.2.2、CP-A1.6）

- 舉債、出售財產、提領存款若不能證明用途 → 列入遺產
- 醫療單據、看護費單據要保留

## 計算範例（給使用者看真實的數字）

### 範例 1：扶養 70 歲母親

```
原本免稅額 = 9.7 萬 × 2 (本人 + 配偶) = 19.4 萬
加扶養 70 歲母親後 = 19.4 + 14.55 = 33.95 萬

若使用者適用稅率 12% → 省稅 14.55 × 12% = 1.746 萬
若使用者適用稅率 20% → 省稅 14.55 × 20% = 2.91 萬
若使用者適用稅率 30% → 省稅 14.55 × 30% = 4.365 萬
```

### 範例 2：勞退自提 6%

```
月薪 8 萬 → 自提 = 8 × 6% × 12 = 5.76 萬／年
年度薪資從 96 萬 → 90.24 萬

若稅率 12% → 省稅 5.76 × 12% = 6,912 元
若稅率 20% → 省稅 5.76 × 20% = 11,520 元
（不含未來退休領取時的稅務）
```

### 範例 3：保險規劃

```
父親 1 億資產，配偶 + 2 子女（皆已成年）
原遺產稅 = (1 億 − 1,333 − 553 − 56×2 − 138) × 15% − 281.05 = 898.55 萬

若 4,000 萬投保壽險（要保人=被保險人=父親，受益人=子女）
新遺產淨額 = (1 億 − 4,000 萬) − 1,333 − 553 − 112 − 138 = 3,864 萬
新遺產稅 = 3,864 × 10% = 386.4 萬

省 = 898.55 − 386.4 = 512.15 萬

且每子女 2,000 萬保險給付不計入最低稅負（< 3,740 萬／戶）
```

## 報告長度建議

- **使用者需求單純**（只問怎麼報今年的稅）：報告約 500-800 字
- **使用者要中長期布局**：800-1,500 字
- **使用者要傳承規劃**：1,500-3,000 字

不要為了「看起來完整」硬塞建議——只列**真正適用使用者**的項目。

## 結束語

每份報告結尾都要加一句：

> 實際申報前建議再用最新法令確認，金額較大或情況複雜的項目（保險規劃、遺產傳承、不動產買賣、跨境稅務）建議諮詢會計師或國稅局。
