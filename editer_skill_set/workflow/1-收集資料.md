# 第 1 步：收集使用者資料

## 收集原則

- 一次只問 2-4 個問題，分批問。
- 使用 `AskUserQuestion` 工具，每題提供清楚的選項。
- 從「基本資料」開始，再到「所得結構」、「既有扣抵」、「資產」、「生命階段」。

## 第 1 批：基本資料（必問）

```
- 年齡（決定免稅額是 9.7 萬或 14.55 萬）
- 婚姻狀況（影響配偶免稅額、合併申報）
- 子女狀況（人數、年齡、是否就讀大專、是否身心障礙）
- 扶養其他親屬（父母是否 70 歲以上、是否同住、是否在報你的扶養）
```

### 範例問法

| 問題 | 選項 |
|------|------|
| 你今年的年齡？ | <40 / 40-50 / 50-60 / 60-70 / >70 |
| 婚姻狀況？ | 單身 / 已婚 / 離異 / 喪偶 |
| 有幾個小孩？ | 0 / 1 / 2 / 3 / 3+ |
| 父母是否健在？ | 都健在 / 一方健在 / 都已過世 |

## 第 2 批：所得結構（必問）

```
- 薪資所得（年薪約多少、有無自願提繳勞退 6%）
- 執行業務所得（自由業、保險業務員、醫師等）
- 租賃所得（包租公／包租婆）
- 股利所得（金額、是否選分開計稅）
- 利息所得（存款、債券、ETF 配息）
- 海外所得（有無超過 100 萬）
- 退職所得（今年是否退休、一次領或分期）
- 其他所得（中獎、稿費版稅、賣二手物等）
```

### 範例問法

| 問題 | 選項 |
|------|------|
| 主要所得來源？ | 薪資為主 / 自由業 / 包租公 / 投資為主 / 多元 |
| 年度薪資總額（粗估）？ | <100 萬 / 100-243 萬 / 243-500 萬 / >500 萬 |
| 有沒有自願提繳勞退 6%？ | 有 / 沒有 / 不知道是什麼 |
| 海外所得（含港澳）超過 100 萬嗎？ | 沒有 / 有 / 不確定 |

## 第 3 批：既有扣抵（必問）

```
- 標準扣除額 vs. 列舉扣除額（哪個有利）
- 列舉項目：保險費、醫藥費、捐贈、災損、購屋借款利息、房屋租金
- 特別扣除額：薪資特扣（定額 vs. 核實）、儲蓄投資、教育學費、身心障礙、幼兒、長照、租金、財產交易損失
- 個人投資新創／文創（《產創》《生技醫藥》《文創》條例）
```

### 範例問法

| 問題 | 選項 |
|------|------|
| 你今年用標準扣除還是列舉扣除？ | 標準 / 列舉 / 不確定哪個好 / 沒報過稅 |
| 有買保險繳保費（人身保險）嗎？ | 有，自己 / 有，配偶／子女 / 沒有 |
| 有付房貸利息嗎？ | 有 / 沒有 / 房子在配偶名下 |
| 有租屋繳租金嗎？ | 自住租屋 / 不是租屋者 / 配偶名下有房 |
| 有家人需要長期照顧（外籍看護／長照／巴氏量表者）嗎？ | 有 / 沒有 |

## 第 4 批：資產狀況（依需求問）

```
- 不動產（幾間、自住或出租、買進年份、房貸餘額）
- 保險（壽險／儲蓄險／投資型保單；要保人／被保險人／受益人關係）
- 存款（粗估金額——影響儲蓄投資特扣、遺產稅試算）
- 股票（境內／境外、上市櫃／未上市櫃）
- 海外資產（CFC 風險）
- 過去 2 年贈與紀錄（擬制遺產風險）
```

### 範例問法

只在使用者表達想做傳承規劃、贈與規劃、不動產處分時問這層。

| 問題 | 選項 |
|------|------|
| 名下不動產幾間？ | 0 / 1（自住） / 2（自住+出租） / 3+ |
| 你的人身保險的要保人和被保險人是同一人嗎？ | 都是同一人 / 不一樣 / 不確定 |
| 過去 2 年內有大額贈與配偶或子女嗎？ | 沒有 / 有，金額 <244 萬 / 有，金額 >244 萬 |

## 第 5 批：生命階段需求（依需求問）

```
- 即將買房／賣房
- 即將結婚／子女即將結婚
- 即將生小孩
- 即將退休／已退休
- 想做傳承規劃（信託、保險、贈與、控股公司）
- 婚姻狀況變動（離婚、配偶過世）
- 海外移居計畫（高飛策略）
```

### 範例問法

| 問題 | 選項 |
|------|------|
| 未來 1-2 年有什麼重要計畫？ | 買房 / 賣房 / 結婚 / 生子 / 退休 / 傳承 / 沒特別 |
| 想規畫的目標？ | 今年報稅省稅 / 中長期布局 / 兩個都要 |

---

## 收集後的確認步驟

收完資料後，**用條列式整理一份「使用者狀況摘要」給使用者確認**，避免後面建議建立在錯誤資訊上。

```markdown
我整理一下你的狀況：

- 年齡 X / 婚姻 X / 子女 X
- 主要所得：薪資 X 萬 + 股利 X 萬 + 租賃 X 萬
- 已申報項目：標扣 / 列扣（保險費 X 萬、購屋利息 X 萬）
- 特扣已用：薪資 21.8 萬 + 儲蓄投資 X 萬
- 特殊狀況：扶養 70 歲母親、有買新創公司股票、有海外所得 X 萬

確認沒問題的話，接著我來幫你檢核可優化的項目。
```
