# 寫作用 prompt 範本（事前約束）

這份 prompt 是給「寫作前」用的，跟主 skill 的「事後審查」是兩個用途。建議流程：

1. 寫的時候只給 AI 規則二、規則三的限制（歪、動），讓它寫得放鬆
2. 寫完後跑主 skill 做事後審查
3. 補錨這一步只能由作者自己做

如果硬要把三條規則一次塞給 AI，AI 會出現「假歪」（為了不對稱而刻意把句子斷得詭異，像裝口吃）跟「規避型僵化」（為了避開禁用詞而用更彆扭的同義替換）。所以規則一（錨）原則上不要在寫的時候硬塞，留給審查階段標出來、作者自己補。

---

## 完整版 prompt（僅在使用者堅持要邊寫邊套規則時用）

```
你要用中文幫我寫東西。動筆之前先看下面三條規則。每寫完一段就回頭檢查，違反任何一條就重寫那段。

【規則一：錨】
每三段以內至少要出現一個具體錨點：明確的時間（哪一年哪個月哪天哪個時段）、明確的地點（哪家店、哪條街、哪個區）、明確的人名（用真名或編一個具體名字，不准只說「朋友」「某人」「我認識的人」）、或明確的感官細節（醬油、燈光、味道、聲音、皮膚感覺）。
禁止飄詞：「在這個忙碌的城市裡」「某個午後」「曾經有個人告訴我」「某種程度上」「在這個快節奏的時代」「某個朋友」。
若手上沒有具體錨點可以用，請在該處寫【補錨：什麼時候？哪裡？跟誰？】，不要瞎編。

【規則二：歪】
句子長度要跳動。禁止連續三個結構對稱的句子。
禁止這些句型：
- 「她不是 X，她是 Y」「這不是 A，這是 B」
- 「不是逃避，不是妥協，而是放下」這類三段否定肯定
- 「○○、○○、○○」三項對稱並列收尾
- 「願妳○○、願妳○○、願妳○○」這類祝福對仗
偶爾要刻意斷一個短句出來，三個字、五個字都行。

【規則三：動】
禁止把動詞變名詞。具體禁用詞組：
- 「對○○的探索／覺察／反思／重構／告別／追尋」
- 「○○感」「○○性」「○○化」
- 「以○○的姿態」「以○○的方式」
- 「值得我們深思」「令人深省」「發人深省」
- 「在某種意義上」「歸根究底」「本質上來說」「不可否認」
能用動詞的地方就用動詞：她「哭了」、不是她「陷入了情緒的低谷」。

寫完之後自己掃一遍，把違反任一條的句子標出來重寫。

---
主題：【填】
讀者是誰：【填】
篇幅：【填】
你想要的語氣（例如：像跟朋友吃飯講事情、像在臉書貼文、像寫部落格）：【填】
我能提供的具體錨點（時間、地點、人名、感官細節，越多越好）：【填】
```

## 輕量版 prompt（推薦：寫的時候用這個，事後再審查）

```
你要用中文幫我寫東西。寫的時候遵守兩條：

【規則一：歪】
句子長短要跳動。禁止連續三個對稱句。禁止「她不是 X，她是 Y」「不是 A、不是 B、而是 C」「願妳○○、願妳○○、願妳○○」這類對仗。偶爾要有短句，三五個字一句。

【規則二：動】
禁止把動詞變名詞。禁用「○○感」「○○性」「○○化」「對○○的探索／覺察／反思／告別」「以○○的姿態」「值得我們深思」「令人深省」「在某種意義上」「歸根究底」「本質上來說」。能用動詞就用動詞。

寫完後我會用 ai-free-editor 跑事後審查，補錨點的工作我會自己做。

---
主題：【填】
讀者：【填】
篇幅：【填】
語氣：【填】
我能提供的具體錨點（時間、地點、人名、感官細節）：【填】
```
