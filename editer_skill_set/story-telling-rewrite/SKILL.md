# 故事型分析文重寫引擎

把一篇硬的、冷的、知識專欄式的文章，重寫成讓讀者「看懂了一個人」的故事型分析文。

核心目標不是讓讀者覺得「這篇好多知識」，而是讓讀者覺得：

- 「原來他不是壞、不是笨、不是自私，而是他站在那個位置時，真的會那樣想。」
- 「原來我以前只是在生氣，現在我看懂了。」
- 「原來這不是八卦，而是一種人生選擇背後的代價結構。」

---

## 第零步之零：題材對齊原則（最最高優先）

**這條規則優先於本文件中所有其他例子。**

本 SKILL.md 為了示範寫法，會大量出現「具體角色＋具體情境」的範例。這些範例分散在多個領域：職場、學習、健康、消費、城市選擇、教育、人際、自我認同、家庭、婚育、財務焦慮等。

**過去版本曾因為範例集中在婚育，導致重寫出來的文章不論原文題材是什麼，最後都被拉到婚姻或家庭場景。這是嚴重錯誤，本版專門修正。**

**正確做法：**

1. 重寫前**先讀原文，找出原文真正在講的領域**（職場？健康？理財？教育？城市選擇？……）。
2. 主角、情境、副標題、表面選擇、害怕失去、其他角色觀點，**全部都要在那個領域內展開**。
3. 本 SKILL.md 範例的功能是**示範句型結構**，不是示範題材。看到範例寫「三十二歲被媽媽問什麼時候結婚」，要學的是「年齡＋處境＋一個外在壓力」這個結構，**不是學「主題要是婚姻」**。
4. 如果原文是講職場績效，主角就要是職場角色；如果原文是講健康習慣，主角就要是健康角色。**不要強行把職場故事拉到「主角後來決定結婚／生小孩」這種結尾**。
5. 寫完後做題材一致性檢查：把原文題材列出來，把成品的角色、副標題、結尾判斷問題列出來，**至少八成以上要落在同一個領域**。沒過 → 重寫。

**寫作中如果有「不知道往哪寫，就寫家庭／婚姻吧」的傾向，立刻停下，回去看原文。**

## 第零步：台灣語氣校準（最高優先）

整篇文章必須符合**台灣人平常的語氣和用字習慣**。這條是最高法則，所有其他規則都在這條之下。

**用字檢查（看到中國用語就改掉）：**

| 中國用語 | 台灣用字 |
|---|---|
| 視頻 | 影片 |
| 質量（品質意義時）| 品質 |
| 信息 | 訊息／資訊 |
| 軟件 | 軟體 |
| 默認 | 預設 |
| 智能 | 智慧／智能（看上下文）|
| 屏幕 | 螢幕 |
| 數據（單獨用）| 數據／資料 |
| 互聯網 | 網路 |
| 創業者 | 創業者（OK）|
| 牛逼／牛 | 厲害／猛 |
| 接地氣 | 貼近生活／實際 |
| 立馬 | 馬上／立刻 |
| 搞笑 | 好笑／搞笑（OK）|
| 高大上 | 高級／講究 |
| 性價比 | CP 值 |
| 老公／老婆 | 老公／老婆（OK，台灣也用）|
| 媳婦（指太太）| 老婆／太太（媳婦在台灣指兒子的太太）|
| 估計（猜測義）| 應該／可能／大概 |
| 整 | 弄／搞 |
| 厲害了 | 厲害／猛 |
| 真香 | 不要用 |
| 卷／內卷 | 競爭激烈（如果讀者不熟）|
| 走心 | 用心／真心 |
| 顏值 | 顏值（OK，台灣也用）|

**台灣口語的真實感（適度用，不要每句都用）：**

- 「真的」當強調詞：「真的差很多」「真的會被氣死」
- 「就」「就是」「然後」當轉折：「他就會覺得……」「然後就……」
- 「蠻」代替「滿／很」：「蠻常見的」「蠻有道理」
- 「啊」「欸」「耶」當尾氣：「不是這樣啊」「真的耶」（偶爾用，不要每段）
- 「OK 啊」「不行欸」「會不會太……」這種日常斷句
- 「老實講」「說真的」「講白一點」當引言

**避免的書面腔（會讓人覺得不是台灣人寫的）：**

- ❌「我們不妨思考……」
- ❌「在某種程度上……」
- ❌「值得注意的是……」
- ❌「綜上所述……」
- ❌「進一步而言……」
- ❌「由此可見……」

寫完後通讀一遍，問自己：**這段話，台灣的朋友會這樣講嗎？** 不會 → 改。

---

## 第一步：找出文章裡的「人」

重寫前，先從原文裡撈出主角。**不要一開始就講制度、經濟、歷史、社會學、心理學。**

回答這六個問題：

- 這篇文章裡，誰卡住了？
- 他卡在哪裡？
- 他以為自己在追求什麼？
- 但他真正害怕失去的是什麼？
- 他的選擇有什麼道理？
- 他的選擇又要付出什麼代價？

如果原文沒有具體人物，**自己造一個合情合理的角色**，給他名字、年紀、處境。

**重要：造的角色與情境必須完全跟著原文題材走，不要套用本 SKILL.md 範例的場景。** 下面是不同題材的範例，只示範「具體化」的寫法，不示範題材本身：

- 職場題材：「四十一歲的阿凱，在電商公司當行銷主管，下面帶八個人，最近被約去談 PIP（績效改善計畫）」
- 學習與職涯轉換：「二十七歲的小宇，做了三年工程師，存了六十萬，正在猶豫要不要辭職全職準備考研」
- 健康與自我照顧：「五十三歲的玉芬阿姨，剛被診斷糖尿病前期，醫生叫她戒手搖飲，她戒了兩週又買回來」
- 消費與金錢：「三十六歲的怡君，家庭月收十二萬，每個月帳單還是月光，自己也說不出錢花到哪去」
- 城市選擇：「二十九歲的阿翔，台南長大、台北工作五年，最近爸爸中風，他在猶豫要不要回去」
- 教育與小孩：「三十八歲的雅婷，小孩讀小三，被導師約談說孩子在班上沒朋友，她那天哭了一整晚」
- 人際與友情：「三十四歲的志豪，發現大學時最好的朋友把他從群組默默踢掉，他不知道發生什麼事」
- 自我認同：「四十六歲的建宏，工程師，最近開始懷疑自己這二十年是不是走錯路了」
- 婚育（只是其中一種，不是預設）：「三十二歲的小婷，月薪四萬八，最近被媽媽問什麼時候要結婚」

選範例的方式：**讀原文 → 確認原文在講什麼領域 → 在那個領域內造角色**。原文在講職場就造職場角色，原文在講健康就造健康角色，**不要因為 SKILL.md 範例好寫就把所有題材都拉回婚姻或家庭**。

---

## 第二步：寫一個具體開場

文章開頭要先出現一個具體情境或具體人物，讓讀者感覺：

- 「這不就是我朋友？」
- 「這不就是我家人？」
- 「這不就是我自己？」

---

## 第三步：表面選擇 vs 真正害怕失去的

寫這個人**表面上**在做什麼選擇。例子（**只是示範格式，題材跟著原文**）：

- 職場：「他寧可被資遣也不想被調職」「她每天加班到十點，不回家」
- 學習轉換：「他做到一半把碩士休學了」「她考了三年公職，今年決定不考了」
- 健康：「他知道要戒酒，但每週還是喝四天」「她說要運動，買了三家健身房都沒去」
- 消費：「他月薪八萬，戶頭只有兩萬」「她寧可吃泡麵，也要每年換新手機」
- 城市選擇：「他爸生病了，他還是不想回家鄉」「她在台北住了十年，最近一直在看花蓮的房子」
- 教育：「她不讓小孩補習，全班只有她家不補」「他堅持讓孩子讀體制外，被全家反對」
- 人際：「她跟好朋友冷戰半年，就是不肯先傳訊息」「他刪了所有同學群組」
- 自我認同：「他四十歲了還在換工作」「她做到資深了，突然說想去開花店」
- 婚育（其中一種而已）：「她不想結婚」「他不想生小孩」

然後往下挖一層，寫他**真正害怕失去**的是什麼——通常不是表面那個東西，而是某種更底層的東西：自由、掌控感、被看見、不再被愛、再也回不去的版本的自己。

這一層是文章的心臟。讀者要在這裡產生「原來如此」的感覺。

---

## 第四步：至少寫出三種角色的內在邏輯

同一件事，不能只寫單一角色的道理。請至少寫出三種角色看同一件事的內在邏輯。

**寫法的關鍵：**

- 每個角色都要寫出他**相信什麼**、**害怕什麼**、**委屈在哪裡**、**承受什麼代價**。
- 不要把任何一方寫成單純的壞人、笨人、自私的人。
- 要讓讀者看到：**每一種選擇背後都有它的道理，也都有它的代價。**

---

## 第五步：用一本書（或一個觀念）收束

文章中要找到一本書、或一種書中的核心智慧，作為理解這件事的框架。

**這本書不是裝飾，也不是硬塞書名。** 它的功能是：

- 把混亂的情緒變成清楚的結構。
- 讓讀者從「我很氣」變成「我看懂了」。

**寫法：**

- 用簡單口語解釋這本書的觀念，**不要寫成書摘**。
- 不要說「這本書談到的是……」這種介紹腔。改成：「有一本書叫《XX》，它講了一件我覺得很重要的事——」
- 然後把這個觀念套回文章主題，幫讀者看懂角色為什麼會那樣選。

---

## 第六步：給讀者一個可以帶走的判斷問題

文章最後**不要只做漂亮結論**。一定要給讀者一個下次可以使用的提醒、問題、或判斷方式。

讓讀者覺得：

- 「我下次會看得更深一層。」
- 「我不只是學到知識，而是多了一種判斷能力。」

---

## 文章結構（內在順序，不要當小標寫出來）

1. 一個具體的人或情境
2. 這個人表面上在做什麼選擇
3. 往下挖他真正害怕失去什麼
4. 換其他角色看同一件事
5. 用一本書或一個觀念收束
6. 給讀者一個可以帶走的判斷問題

---

## 副標題規則

- **不要沿用原文標題。** 全部重寫。
- 副標題要有**情緒、有問題感、有故事感**。
- 不要寫「一、背景說明」「二、現況分析」這種報告腔。
- 改成像（**只是示範語感，題材跟著原文**）：
  - 職場：「他不是不想升遷，他是不想再被當成那個永遠不會說不的人」
  - 健康：「她不是懶得運動，她是怕一旦開始照顧自己，就要承認這幾年活得多隨便」
  - 消費：「他不是不會理財，他是不想看到帳戶數字證明這幾年都白做了」
  - 城市選擇：「她不是不想回家，她是怕一回去就再也走不出來」
  - 教育：「他不是反對補習，他是怕小孩變成另一個討厭學習的自己」
  - 人際：「她不是真的生那麼大的氣，她是怕原諒了之後又被傷一次」
  - 自我認同：「他不是中年危機，他是第一次有勇氣承認那不是他想要的人生」
  - 婚育（其中一種而已）：「她不是不想結婚，她是不想再變回那個被需要的人」

---

## 段落之間的銜接

段落之間、小節之間，**用反問句或設問句引導讀者繼續看**。

不要用平鋪直敘的陳述句做銜接。

**避免這樣寫：**

- ❌「接下來我們來談……」
- ❌「以下說明……」
- ❌「關於這個問題……」

**改成這樣：**

- ✅「那為什麼她明明知道，還是這樣選？」
- ✅「但這真的只是她一個人的問題嗎？」
- ✅「如果換成爸媽的角度呢？」

**使用方式（避免跟「文章式排版」打架）：**

設問句作為銜接時，預設放在**下一段的段首**，再接續展開。不要每個問句都單獨拆成一行短段，那會讓文章變成 Threads 風格的碎片。只有在真的需要停頓、加重語氣的關鍵轉折，才把問句拆出來獨立成段。

## 數字處理

重要數字請用**國字**寫：

- 百分之六（不是 6%）
- 一千萬
- 三十歲
- 七成
- 二十年

**例外（維持原樣）：**

- 金融代號、股票代號、ETF 名稱：0050、0056、ETF
- 西元年份：2026 年
- 具體金額且為列表時可保留阿拉伯數字（情境判斷）

---

## 節奏控制

- **每段以五到八句為主**，讓文章有完整閱讀感，不要寫成一兩句就換行的社群短句。
- **每段只推進一個主要觀念**，但要把場景、情緒、解釋與收束放在同一段裡講完整。
- **先鋪墊 → 再解釋 → 最後收結論**，不要一開頭就丟結論。
- 抽象論述不要連續超過兩段，要拉回具體場景。

---

## 文章式排版

輸出要像一篇可以直接發布的長文，不要像簡報筆記、Threads 貼文、或一句一行的金句集合。

- 開頭可以用一到兩個較完整的段落建立人物、場景與問題感，不要每句都拆行。
- 「具體開場」「情境引言」「角色對白」這類場景化片段，可以較短（兩三句即可），不受五到八句限制；但內文論述段落要寫飽滿。
- 小節內文每段要有自然起承轉合，通常是一個情境或觀點完整講完後才換段。
- 可以保留 `##` 副標題，但副標題之間不要切得太碎；每個小節至少要有兩到三個完整段落。
- 問句、金句、關鍵句可以獨立成段，但要少量使用，只有在真正需要停頓或加重語氣時才拆出來。
- 避免連續出現多個只有一句話的段落。若只是同一個意思的延伸，合併成一段。
- 排版目標是「正式文章感」：讀起來順、段落飽滿、氣口穩，不是短影音文案或社群碎片。

---

## 格式要求

- **不要用 `---` 分隔線**（這個 skill 跟 stanley-write 不同，不走 slides-to-obsidian 格式）
- **不要用 `——`（中文破折號／em dash）**。這個符號太書面、太翻譯腔，台灣朋友講話不會這樣斷句。需要停頓或補充時，用句號斷開、用逗號接續、用括號補充、或直接拆成兩句話。
- **不要寫成條列式大綱**
- 要寫成**一篇完整的文章**
- 可以有副標題（用 `##`），但每個小節都要像文章的一部分，而不是簡報筆記
- 要日常口語
- 字數建議 1500-2500 字（多角色觀點需要篇幅鋪陳）

## 自我檢查清單（寫完後逐項過）

寫完後，逐項檢查。沒過就改：

0. **題材對齊（最重要）**：原文在講什麼領域？成品的主角、情境、副標題、結尾判斷問題，是不是都落在同一個領域？有沒有不自覺把題材拉到婚姻、家庭、生育？沒對齊 → 整篇重寫。
1. **台灣語氣**：通讀一遍，有沒有中國用語？有沒有書面腔？台灣朋友會這樣講嗎？
2. **具體開場**：前三段內有沒有一個具體的人或情境？
3. **多角色內在邏輯**：有沒有寫出至少三個角色的「相信什麼／害怕什麼／委屈在哪裡／代價是什麼」？
4. **一本書的智慧**：有沒有引一本書或一個概念，幫讀者把混亂變清楚？
5. **代價結構**：有沒有讓讀者理解「每個選擇都有道理，也都有代價」？沒有把任何一方寫成壞人？
6. **可帶走的判斷問題**：結尾有沒有給讀者一個下次可以用的提醒、問題或判斷方式？
7. **副標題**：每個副標題單獨讀，有沒有情緒、問題感、故事感？還是只是描述？
8. **銜接方式**：段落之間有沒有用設問句／反問句銜接？
9. **文章式排版**：段落有沒有五到八句左右的完整閱讀感？有沒有太多一句一段、短句碎片？
10. **節奏**：有沒有一段塞太多觀念？有沒有連續兩段以上都在抽象論述？
11. **數字**：重要數字有沒有用國字？
12. **破折號**：通篇有沒有用到 `——`？有 → 全部改成句號斷句、逗號接續或括號補充。

## 觸發範例

使用者：「幫我把這篇文章重寫成故事型分析文。」（附原文）

Claude：
1. 先讀完原文，找出主角（如果沒有就造一個合情合理的）
2. 列出主角的表面選擇 vs 真正害怕失去的
3. 列出至少三個角色的內在邏輯
4. 找一本書或一個概念當框架
5. 想一個讀者可以帶走的判斷問題
6. 按結構寫初稿
7. 用自我檢查清單逐項過
8. 在對話裡呈現完整文章

## 最高法則

**題材有沒有跟著原文走？** 沒有（被拉到婚姻／家庭／生育之類預設場景）→ 整篇重寫。

**台灣的朋友會這樣跟你講話嗎？** 不會 → 改。

**讀完之後，讀者是「學到知識」，還是「看懂了一個人」？** 如果只是學到知識 → 重寫。

這三條覆蓋一切，順序就是優先順序。
